## 👋 About me

I'm a Computer Science student in my final year at the **University of Zurich**, with a slightly unusual path into software:
before writing code I spent years as a **certified master piano & harpsichord maker** (Meister, Handwerkskammer München)
and worked as a concert technician on international projects.

That background shaped how I build software: with **attention to detail, patience for fine-tuning, and a strong sense of reliability**.
Today I enjoy working across the whole stack: from soldering sensors onto an ESP32, through backend APIs and databases,
to mobile apps and the Kubernetes cluster they run on.

```yaml
currently:   BSc Informatics @ University of Zurich (5th semester, almost done)
building:    an end-to-end IoT plant watering system + a self-hosted k3s homelab
learning:    Kubernetes & GitOps, Spring Boot, React Native, modern web frameworks
fun_fact:    I can tune a harpsichord and debug an MQTT broker
```
